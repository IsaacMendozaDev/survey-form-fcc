# Survey Form Project

This project is part of the FreeCodeCamp curriculum. It is a simple survey form built using HTML and CSS.

## Project Structure

- `index.html`: The main HTML file containing the structure of the survey form.
- `styles.css`: The CSS file containing the styles for the survey form.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/yourusername/survey-form-fcc.git
```

2. Navigate to the project directory:

```bash
cd survey-form-fcc
```

3. Open `index.html` in your web browser to view the survey form.

## Features

- Responsive design
- User-friendly interface
- Basic form validation
